Setup guide

Keep your AnyoneNear computer running

AnyoneNear reads your Facebook groups from Chrome on one computer. It checks them around the clock, so posts from late at night, and posts a group admin approves hours later, are waiting for you in the morning. That only works while that computer is on, awake and running Chrome. This guide shows how to set it up once so it keeps going on its own.

Recommended

Use a computer that does only this

The best results come from a computer that stays on all the time and does nothing but run AnyoneNear. Nobody closes Chrome, minimizes the window, shuts it down at night or takes it to a job.

  • An old laptop or a small desktop is plenty. Any Windows 10/11 PC or Mac that runs current Chrome. A new mini PC costs roughly $150–$300.
  • Costs about a dollar or two a month in electricity for a mini PC or laptop left on all month.
  • Keep it plugged in, on your internet (a network cable is best), with a screen attached. No screen? A $10 "HDMI dummy plug" makes the computer think one is there.
  • Sign in to Facebook once in Chrome with "Keep me signed in", open the AnyoneNear app there and connect it (Watch → Connect this computer). Then leave it alone.

Using the computer you work on?

That works too. A few habits make the difference:

When nobody has touched the computer for a few minutes, AnyoneNear brings its window back to the front by itself if it was hidden.

Set it up in 5 minutes

The setup file does steps 1 to 4 for you. Open it on the computer AnyoneNear runs on and follow what it says. It changes nothing else, and the "undo" file puts everything back.

Windows

Download setup for WindowsUndo

After it downloads, double-click it. If Windows shows "Windows protected your PC", click More info → Run anyway (it's a plain text file you can open in Notepad to read first).

Or do it by hand
  1. Never sleep when plugged in: Settings → System → Power & battery → Screen and sleep → "When plugged in, put my device to sleep after" → Never.
  2. Laptop lid: Control Panel → Power Options → "Choose what closing the lid does" → When plugged in: Do nothing.
  3. No password when it wakes: Settings → Accounts → Sign-in options → "If you've been away, when should Windows require you to sign in again?" → Never. Screen saver: None.
  4. Chrome setting: right-click your Chrome shortcut → Properties → at the end of Target, after chrome.exe", add a space and --disable-backgrounding-occluded-windows → OK. Close every Chrome window and open Chrome from that shortcut. To start it with Windows, press Win+R, type shell:startup and copy the shortcut into that folder.
  5. In Chrome: Settings → System → "Continue running background apps when Google Chrome is closed" → On.

Mac

Download setup for MacUndo

After it downloads, right-click it → Open → Open (the first time only, since it's not from the App Store). If it won't run, open Terminal and type chmod +x followed by a space, drag the file into the window, press Return, and try again.

Or do it by hand
  1. Never sleep: System Settings → Battery (or Energy) → turn on "Prevent automatic sleeping when the display is off" (on laptops: under Options, when on power adapter).
  2. No password when it wakes: System Settings → Lock Screen → "Require password after screen saver begins or display is turned off" → Never.
  3. Chrome setting: quit Chrome, open Terminal and run open -a "Google Chrome" --args --disable-backgrounding-occluded-windows. Do this each time you start Chrome on this Mac (the setup file does it for you at every login).
  4. Open at login: System Settings → General → Login Items → add Google Chrome (the setup file does this with the setting included).

Then, in Chrome on that computer

  1. Stay signed in to Facebook ("Keep me signed in"). If Facebook signs you out, AnyoneNear can't read your groups.
  2. Open the AnyoneNear app, go to Watch and tap Start monitoring. The "AnyoneNear monitoring" window opens.
  3. Leave that window open, somewhere on screen or on a second monitor. Optional on Windows: Microsoft PowerToys can keep it on top (click the window, press Win + Ctrl + T).
  4. Restart the computer once to check that Chrome and monitoring come back by themselves.

Check that it's working

  • The app's status bar says "Your computer is monitoring" with a recent check time. At night it says it's checking overnight and when replies go out.
  • The Scan log (Watch screen) lists every group visit. Visits should say "caught up" or "daily deep check", not "window hidden".
  • The first morning after setup, open the Scan log and look for visits during the night. If they say "window hidden" while the screen was off, set the screen to never turn off (you can still switch the monitor off with its own power button).
  • If the computer stops, you get one alert in the morning saying so, and when it's back it reads the last two days of each group, so late posts aren't lost.

Questions

Does it reply to people in the middle of the night?

No. It reads your groups around the clock, but replies wait for your hours (7 AM to 10 PM by default) so your Facebook activity looks like a person's. If you're a 24-hour business, turn on "Reply any time" in the app under Watch → Replies. Daily limits and spacing still apply.

Will it catch posts a group admin approves hours later?

Yes. Once a day it goes back through the last two days of each group to pick up posts that were approved late.

Can I still use this computer?

Yes, as long as you leave the AnyoneNear window open and don't minimize it. A dedicated computer just removes the chance of it being closed by accident.

Is it safe to leave a computer on all the time?

Yes. Computers are built for it. Keep it somewhere with airflow, plugged into a surge protector, and let Windows or macOS install updates. Restarts are fine; AnyoneNear picks up again by itself.
